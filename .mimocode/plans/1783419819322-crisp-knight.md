# V2 版本开发计划（血肉版）

## V2 功能需求总览（来源：PRD-v2.md）

| 编号 | 功能 | 说明 | 交互方式 |
|------|------|------|----------|
| F1 | 视角控制 | 第一人称/第三人称有限/上帝视角 | 表单下拉选择 |
| F2 | 节奏调节 | 紧凑型/舒缓型/标准型 | 表单单选 |
| F3 | 语言风格预设 | 风格 + 强度（轻度/中度/重度） | 风格后强度滑块 |
| F4 | 叙事张力增强 | 冲突设计+悬念设置+反转安排 | 勾选框 |
| F5 | 细节填充 | 环境描写+心理活动+对话润色 | 默认启用，无交互 |
| F6 | 多轮对话润色 | 重写/扩写/精简段落 | 段落末尾按钮 |

## 非功能需求

- 润色响应时间 ≤ 5 秒
- 风格强度一致性校验
- 节奏模式字数偏差 ±15%
- 多轮润色保留历史版本（最多 3 版）

## F6 润色功能详细设计

### 数据库表：paragraph_versions

```sql
CREATE TABLE paragraph_versions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    novel_id INTEGER NOT NULL,
    chapter_index INTEGER NOT NULL,
    paragraph_index INTEGER NOT NULL,
    action TEXT NOT NULL,          -- rewrite/expand/compress
    content TEXT NOT NULL,         -- 润色后的内容
    version INTEGER NOT NULL,     -- 版本号 1/2/3
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (novel_id) REFERENCES novels(id)
);
```

### API 端点：POST /api/v2/refine

请求体：
```json
{
  "novel_id": 1,
  "chapter_index": 0,
  "paragraph_index": 2,
  "action": "rewrite",
  "original_content": "原文内容...",
  "context": "上下文信息..."
}
```

响应：SSE 流式返回润色内容

### 前端组件

**ParagraphActions.jsx** — 段落操作按钮：
- 重写：重新生成该段落
- 扩写：增加更多细节
- 精简：压缩到核心内容
- 版本历史：查看/回退历史版本

**RefinePanel.jsx** — 润色面板：
- 显示当前段落的 3 个版本
- 点击版本可预览
- 确认/取消按钮

## 验证方案

### 功能验证

1. **F1-F4 表单验证**：
   - 启动 V2 后端和前端
   - 在 NovelForm 中选择视角/节奏/强度/张力选项
   - 生成小说，检查生成结果是否符合选择

2. **F5 细节填充验证**：
   - 生成小说，检查是否包含环境描写、心理活动、对话润色

3. **F6 润色验证**：
   - 生成小说后，在段落末尾点击重写/扩写/精简
   - 检查润色结果是否流式返回
   - 检查历史版本是否正确保存（最多 3 版）
   - 检查版本回退功能
