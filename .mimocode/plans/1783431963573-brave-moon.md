## 四、Hermes Agent MCP 桥接

> Hermes 是一个独立的 AI Agent 框架，支持 cron 任务、浏览器自动化、邮件、文档创建、WhatsApp/Slack 消息等。通过 hermes-mcp 桥接，可以让 Claude Code 委托任务给 Hermes。

### 前置条件
- 需要先安装并运行 Hermes Agent（`pipx install hermes-agent`）
- 需要 cloudflared 或 ngrok 用于公网 HTTPS 访问
- 需要 OAuth 2.1 配置

### 安装步骤

```bash
# 1. 安装 hermes-mcp
pipx install hermes-mcp

# 2. 生成 OAuth 凭证
hermes-mcp mint-client

# 3. 启动 cloudflared 隧道（测试用）
cloudflared tunnel --url http://127.0.0.1:8765

# 4. 配置环境变量
export OAUTH_CLIENT_ID=<from step 2>
export OAUTH_CLIENT_SECRET=<from step 2>
export OAUTH_ISSUER_URL=https://<tunnel-url>
export MCP_ALLOWED_HOSTS=<tunnel-hostname>
export HERMES_API_KEY=<from ~/.hermes/.env>

# 5. 验证
hermes-mcp doctor

# 6. 启动服务
hermes-mcp serve
```

### MiMoCode 配置

在 `~/.config/mimocode/mimocode.jsonc` 的 `mcp` 中添加：

```jsonc
"hermes": {
  "type": "remote",
  "url": "https://<your-tunnel-url>/mcp",
  "headers": {
    "Authorization": "Bearer ${HERMES_MCP_BEARER_TOKEN}"
  }
}
```

## 注意事项

- `security-guidance` 会调用 LLM 进行 diff review，消耗 API 额度
- `github` MCP 需要 `GITHUB_PERSONAL_ACCESS_TOKEN` 环境变量
- Hermes MCP 需要先安装并运行 Hermes Agent
- 部分插件（semgrep、sonarqube）需要对应的外部服务
- LSP 插件需要对应的命令行工具已安装
- Go LSP 需要先安装 Go，C/C++ LSP 需要先安装 llvm
