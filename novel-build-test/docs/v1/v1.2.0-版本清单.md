## 四、仍存在的限制

1. **AI 依赖**: 所有 Agent 调用 LLM 需要配置 API Key（.env 中设置）
2. **基础设施依赖**: Qdrant/Redis 未启动时对应功能降级运行，不影响核心 CRUD
3. **Mock 实现**: 辩论/聊天/数据库调优/助手 的部分响应为 mock 数据
4. **前端页面**: 大部分页面仍为 `PlaceholderPage`，需逐个实现真实 UI
5. **测试覆盖**: 后端 37 个路由文件缺少单元测试
