## 二、Agent 增强（P0）

### 2.1 Agent 编排引擎
- [x] 工作流 DAG 执行器: 支持将多个 Agent 按 DAG 编排执行（基础版）
- [ ] 步骤依赖解析: 自动识别输入输出依赖，并行执行无依赖步骤
- [ ] 断点续跑: 失败步骤可重试，从断点恢复工作流
- [ ] 人工审核节点: 工作流中插入人工审核步骤，审批后继续执行

### 2.2 MCP 工具调用
- [ ] MCP 工具注册中心: 统一管理 Agent 可调用的外部工具
- [ ] 工具调用权限: 基于角色的工具使用权限控制
- [ ] 工具执行日志: 完整记录每次工具调用的入参、出参、耗时
- [ ] 自定义工具 SDK: 提供 Python SDK 让用户注册自定义 MCP 工具

### 2.3 多 Agent 协作
- [ ] 辩论引擎升级: 多 Agent 多轮辩论，自动生成辩论摘要和结论
- [ ] 协作任务分配: 主 Agent 拆解任务 -> 分配给子 Agent -> 汇总结果
- [ ] 上下文共享: Agent 间共享对话上下文和历史
- [ ] 投票/共识机制: 多 Agent 对同一问题给出答案，投票选取最优

### 2.4 知识库 RAG 增强
- [ ] 多知识库: 支持创建多个知识库（项目级、团队级、全局级）
- [ ] 文档解析器: PDF/Word/Markdown/代码文件自动解析 + 分块
- [ ] 混合检索: 关键词（BM25）+ 向量语义（Qdrant）混合检索
- [ ] 引用溯源: Agent 回答时自动标注知识来源
- [ ] 知识库热更新: 文档更新后自动重新索引，无需重启

## 三、测试能力（P0）

### 3.1 AI 驱动测试生成
- [ ] 需求->测试用例: 输入需求文档，AI 自动生成功能/接口/UI 测试用例
- [ ] 代码->接口测试: 分析 API 代码，自动生成接口测试脚本
- [ ] UI 截图->元素定位: 上传 UI 截图，AI 生成 Playwright/Cypress 选择器
- [ ] 历史缺陷->新用例: 基于历史缺陷模式，推荐新增测试覆盖

### 3.2 可视化测试报告
- [ ] 报告仪表盘: 测试通过率趋势图、模块分布饼图、耗时热力图
- [ ] 失败智能分析: AI 自动分析失败原因
- [ ] 截图对比: 基线截图 vs 实际截图并排对比
- [ ] PDF/Excel 导出: 一键导出测试报告

### 3.3 CI 集成深度优化
- [ ] GitHub/GitLab WebHook: 代码推送自动触发测试执行
- [ ] PR 评论机器人: 测试结果自动评论到 PR 中
- [ ] 增量测试: 仅运行变更代码相关的测试用例
- [ ] 测试环境自动部署: CI 中自动部署临时环境

### 3.4 测试数据工厂
- [ ] AI 数据生成: 基于 Schema 自动生成测试数据
- [ ] 数据脱敏: 生产数据导入时自动脱敏
- [ ] Mock Server: 内置 Mock HTTP Server
- [ ] 数据快照: 测试前后数据快照对比
