> 版本: v1.1.0
> 更新日期: 2026-07-15

---

## 一、设计理念

AISQA 前端采用 **"暖白拍立得"** 设计语言，灵感来源于：
- 拍立得相纸的纯白质感与温暖色调
- 老照片的自然随机旋转与双层阴影
- 极简舒适的阅读体验

**关键词**: 温暖、极简、质感、随机、自然

## 三、组件规范

### 3.1 PolaroidCard（拍立得卡片）

```
┌──────────────────────────────────┐  ← 圆角 12px, 纯白背景
│                                  │
│         ┌────────────────┐       │
│         │   图标/颜色区    │       │  ← 64×64 图标或渐变色块
│         │                │       │
│         └────────────────┘       │
│         标题文字                  │  ← text-lg font-semibold
│         辅助统计数字              │  ← text-2xl font-bold amber
│         次要描述                  │  ← text-sm text-muted-foreground
│                                  │
│    ┌────────────────────────┐    │
│    │   底部签名区(signature)  │    │  ← 拍立得底部留白区域
│    │   标签/副标题/状态       │    │
│    └────────────────────────┘    │
│                                  │
└──────────────────────────────────┘
         ↑ 随机旋转 -2deg ~ +2deg
```

规格:
- 宽度: w-72 (288px)
- 背景: white / bg-card
- 圆角: rounded-xl (12px)
- 阴影: shadow-polaroid (自定义多层暖棕阴影)
- 旋转: 随机 -2deg ~ +2deg (每个卡片创建时固定)
- 悬浮: hover:-translate-y-2 hover:rotate-0 hover:shadow-2xl
- 动画: transition-all duration-300 ease-out

### 3.2 PolaroidGrid（卡片矩阵）

- 使用 CSS Grid 布局
- 默认 5 列（公共模块），3~5 列自适应
- 卡片交错排列（自然错落）
- 入场动画：逐张淡入上滑（stagger 0.08s）

### 3.3 双层导航

```
第一层: 首页卡片矩阵 (点击卡片)
              │
              ▼
第二层: 详情页内部 ┌── 左侧导航 ──┐ ┌── 右侧内容 ──┐
                 │ • 概览       │ │              │
                 │ • 列表/表单  │ │  内容区域     │
                 │ • 配置       │ │              │
                 └──────────────┘ └──────────────┘
```

- 左侧导航：w-56，暖白背景，激活项琥珀高亮
- 右侧内容：flex-1，可滚动
- 导航收起态：w-16，仅图标

## 四、模块配置系统

### 4.1 模块定义结构

```typescript
interface Module {
  key: string           // 模块唯一标识
  title: string         // 模块标题
  subtitle: string      // 模块副标题
  icon: LucideIcon      // 模块图标
  color: string         // 模块主题色
  signature: string     // 英文签名
  group: string         // 所属分组
  subFeatures: SubFeature[]  // 二级功能列表
  status?: 'active' | 'pending' | 'beta'
  lastRunTime?: string
}

interface SubFeature {
  key: string           // 功能唯一标识
  title: string         // 功能标题
  subtitle: string      // 功能副标题
  icon: LucideIcon      // 功能图标
  color: string         // 功能主题色
  component: ComponentType  // 功能组件
}
```

### 4.2 分组系统

```typescript
const groupOrder = [
  '公共模块',   // 平台基础设施
  '项目模块',   // 业务管理
  'AI 智能体', // 9 个 Agent
  'AI 测试',   // 测试全流程
  'AI 应用',   // 面向用户的 AI 工具
  'AI 配置',   // Agent 运行所需的全部配置
  '个人设置',  // 用户 + 权限管理
]
```

### 4.3 v1 新增模块

**Skills技能中心** (skills-center):
- 技能注册、MCP工具管理、工具权限控制、技能市场、技能测试、调用日志

## 七、交互动画

| 场景 | 动画 | 实现 |
|------|------|------|
| 首页入场 | 卡片逐张淡入 + 上滑 | framer-motion staggerChildren |
| 卡片悬浮 | translateY(-8px) + rotate(0) + scale(1.02) | CSS transition |
| 页面切换 | 淡入淡出 (fadeIn/out) | framer-motion AnimatePresence |
| 侧边栏展开 | 宽度 0→240px 弹性展开 | CSS transition + spring |
