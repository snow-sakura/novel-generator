# AISQA v1 模块架构

> 版本: v1.1.0
> 更新日期: 2026-07-15

---

## 架构概览

AISQA 采用 **7 大分组 × 21 模块** 的分层架构：

```
┌─────────────────────────────────────────────────────────────┐
│                        AISQA 平台                            │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  公共模块    │  │  项目模块    │  │    AI 智能体         │  │
│  │  (4 模块)   │  │  (5 模块)   │  │    (9 模块)         │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  AI 测试     │  │  AI 应用    │  │    AI 配置          │  │
│  │  (9 模块)   │  │  (3 模块)   │  │    (9 模块)         │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
│  ┌─────────────────────────────────────────────────────────┐│
│  │                    个人设置 (3 模块)                      ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

---

## 分组详情

### 1. 公共模块（平台基础设施）

| 模块 | Key | 二级功能 | 说明 |
|------|-----|---------|------|
| 系统设置 | settings | 系统配置 | 键值配置与全局参数 |
| 审计日志 | audit | 日志列表 | 操作记录与实体轨迹追踪 |
| 认证与安全 | auth | 用户管理 | 注册、登录与令牌管理 |
| 集成与通知 | integration | CI/CD集成、通知渠道、外部工具、设备云 | CI/CD、外部工具与消息推送 |

### 2. 项目模块（业务管理）

| 模块 | Key | 二级功能 | 说明 |
|------|-----|---------|------|
| 项目管理 | projects | 项目列表 | 测试项目全生命周期管理 |
| 需求管理 | requirements | 需求列表 | 需求录入、追踪与状态流转 |
| 测试环境 | environments | 环境列表 | 环境配置、健康检查与部署 |
| 测试资产库 | assets | 资产列表 | 测试数据、脚本、文档管理 |
| AI 知识库 | knowledge | 知识库管理 | 向量知识存储与语义检索 |

### 3. AI 智能体（9 个 Agent）

| 模块 | Key | 签名 | 状态 |
|------|-----|------|------|
| 调度总控 | agent-dispatch | DispatchController | ✅ active |
| 需求分析 | agent-requirements | RequirementsAnalyst | ⏳ pending |
| 测试架构 | agent-architect | TestArchitect | ⏳ pending |
| 测试设计 | agent-designer | TestDesigner | ⏳ pending |
| 用例编写 | agent-casewriter | TestCaseWriter | ⏳ pending |
| 执行分析 | agent-execution | ExecutionAnalyst | ⏳ pending |
| 质量审计 | agent-quality | QualityAuditor | ⏳ pending |
| 成本优化 | agent-cost | CostOptimizer | ✅ active |
| 辩论引擎 | agent-debate | DebateEngine | ⚠️ beta |

### 4. AI 测试（测试全流程）

| 模块 | Key | 二级功能 |
|------|-----|---------|
| 功能测试 | test-functional | 用例管理、用例执行 |
| 接口测试 | test-api | 接口用例、接口自动化 |
| Web 自动化测试 | test-web-auto | 脚本管理、脚本执行 |
| App 自动化测试 | test-app-auto | 脚本管理、设备管理 |
| 性能测试 | test-performance | 压测脚本、实时监控 |
| 安全测试 | test-security | 漏洞扫描、安全报告 |
| UI 测试 | test-ui | 视觉回归、响应式测试 |
| 冒烟测试 | test-smoke | 冒烟用例、自动触发 |
| 测试执行与报告 | execution | 执行记录、测试报告、报告对比 |

### 5. AI 应用（面向用户的 AI 工具）

| 模块 | Key | 二级功能 |
|------|-----|---------|
| AI 聊天室 | ai-chatroom | 聊天室 |
| AI 数据库调优 | ai-db-tuning | 数据库诊断 |
| AI 助手 | ai-assistant | 全屏助手 |

### 6. AI 配置（Agent 运行所需的全部配置）

| 模块 | Key | 二级功能 | 状态 |
|------|-----|---------|------|
| 模型配置 | model-config | Provider管理、模型列表、分级策略、成本监控 | ⏳ |
| 提示词工程 | prompt-engineering | Agent提示词、模板库、版本管理、在线调试、Few-shot | ⏳ |
| 去AI味配置 | de-ai | 语言风格、句式多样性、领域术语、人性化、输出模板、强度控制、词频黑名单 | ⏳ |
| 技能配置 | skill-config | Agent技能注册、MCP工具管理、权限控制、技能市场 | ⏳ |
| 工作流配置 | workflow-config | 流程模板、步骤编排、超时重试、断点续跑 | ⏳ |
| 测试数据配置 | test-data | 数据源管理、AI数据生成、数据脱敏、Mock服务 | ⏳ |
| MCP 工具集成 | mcp | 工具列表、工具执行 | ⏳ |
| **Hermes智能体配置** 🆕 | hermes-config | 会话管理、消息读写、通道列表、事件轮询、附件管理、权限审批 | ⏳ |
| **Skills技能中心** 🆕 | skills-center | 技能注册、MCP工具管理、权限控制、技能市场、技能测试、调用日志 | ⏳ |

### 7. 个人设置（用户 + 权限管理）

| 模块 | Key | 二级功能 |
|------|-----|---------|
| 个人设置 | personal-settings | 基本信息、修改密码、通知设置、外观偏好 |
| 用户管理 | user-mgmt | 用户列表 |
| 角色管理 | role-mgmt | 角色列表 |

## 数据流

```
用户操作
    │
    ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  前端 UI     │───▶│  API 服务   │───▶│  数据库      │
│  (React)    │◀───│  (FastAPI)  │◀───│  (SQLite)   │
└─────────────┘    └─────────────┘    └─────────────┘
                          │
                          ▼
                   ┌─────────────┐
                   │  AI 引擎    │
                   │  (LLM API)  │
                   └─────────────┘
```

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | React 18 + TypeScript + Vite |
| UI库 | shadcn/ui + Tailwind CSS |
| 动画 | Framer Motion |
| 图标 | Lucide React |
| 状态 | Zustand |
| 后端 | FastAPI (Python) |
| 数据库 | SQLite |
| AI | LangChain + LLM APIs |
