## 1. 项目管理 (projects)

### 1.1 功能清单

| 功能 | 类型 | 说明 |
|------|------|------|
| 项目列表 | READ | 分页查询、搜索、筛选 |
| 项目详情 | READ | 查看项目信息、关联统计 |
| 创建项目 | CREATE | 新建测试项目 |
| 编辑项目 | UPDATE | 修改项目信息 |
| 删除项目 | DELETE | 软删除项目 |
| 项目统计 | READ | 关联模块数量统计 |

### 1.2 API 接口

```
GET    /api/v1/projects              # 项目列表（分页）
GET    /api/v1/projects/:id          # 项目详情
POST   /api/v1/projects              # 创建项目
PUT    /api/v1/projects/:id          # 更新项目
DELETE /api/v1/projects/:id          # 删除项目
GET    /api/v1/projects/:id/stats    # 项目统计
```

### 1.3 数据模型

```sql
CREATE TABLE projects (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    name            TEXT NOT NULL,
    description     TEXT,
    status          TEXT DEFAULT 'active',  -- active/archived
    owner_id        INTEGER REFERENCES users(id),
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    deleted_at      DATETIME
);
```

## 4. 测试执行与报告 (execution)

### 4.1 功能清单

| 功能 | 类型 | 说明 |
|------|------|------|
| 执行记录列表 | READ | 查询执行历史、状态筛选 |
| 执行详情 | READ | 查看执行详情、步骤日志 |
| 创建执行 | CREATE | 发起测试执行 |
| 取消执行 | ACTION | 取消正在执行的任务 |
| 测试报告列表 | READ | 查询报告列表 |
| 报告详情 | READ | 查看报告详情、用例结果 |
| 报告对比 | READ | 多份报告横向对比 |

### 4.2 API 接口

```
GET    /api/v1/executions                # 执行记录列表
GET    /api/v1/executions/:id            # 执行详情
POST   /api/v1/executions                # 创建执行
POST   /api/v1/executions/:id/cancel     # 取消执行
GET    /api/v1/executions/:id/logs       # 执行日志（SSE）

GET    /api/v1/reports                   # 报告列表
GET    /api/v1/reports/:id               # 报告详情
GET    /api/v1/reports/compare           # 报告对比
```

### 4.3 数据模型

```sql
-- 执行记录
CREATE TABLE executions (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id      INTEGER NOT NULL REFERENCES projects(id),
    workflow_id     INTEGER REFERENCES workflows(id),
    name            TEXT,
    status          TEXT DEFAULT 'pending',  -- pending/running/success/failed/cancelled
    started_at      DATETIME,
    finished_at     DATETIME,
    duration_ms     INTEGER,
    error_message   TEXT,
    created_by      INTEGER REFERENCES users(id),
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 执行步骤
CREATE TABLE execution_steps (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    execution_id    INTEGER NOT NULL REFERENCES executions(id),
    step_order      INTEGER NOT NULL,
    agent_key       TEXT NOT NULL,
    status          TEXT DEFAULT 'pending',
    input           JSON,
    output          JSON,
    token_count     INTEGER,
    cost            REAL,
    started_at      DATETIME,
    finished_at     DATETIME
);

-- 测试报告
CREATE TABLE reports (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    execution_id    INTEGER NOT NULL REFERENCES executions(id),
    project_id      INTEGER NOT NULL REFERENCES projects(id),
    summary         JSON,  -- 统计摘要
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
