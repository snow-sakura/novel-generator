## 1. AI 测试模块群

### 1.1 功能测试 (test-functional)

#### 功能清单
| 功能 | 类型 | 说明 |
|------|------|------|
| 用例列表 | READ | 查询功能测试用例 |
| 用例详情 | READ | 查看用例步骤和预期 |
| 创建用例 | CREATE | 新建功能测试用例 |
| 编辑用例 | UPDATE | 修改用例步骤 |
| 删除用例 | DELETE | 软删除用例 |
| 批量导入 | CREATE | Excel/CSV导入用例 |
| 用例执行 | ACTION | 执行单个/批量用例 |
| 执行结果 | READ | 查看执行结果 |

#### API 接口
```
GET    /api/v1/test-functional/cases           # 用例列表
GET    /api/v1/test-functional/cases/:id       # 用例详情
POST   /api/v1/test-functional/cases           # 创建用例
PUT    /api/v1/test-functional/cases/:id       # 更新用例
DELETE /api/v1/test-functional/cases/:id       # 删除用例
POST   /api/v1/test-functional/cases/import    # 批量导入
POST   /api/v1/test-functional/cases/:id/run   # 执行用例
```

#### 数据模型
```sql
CREATE TABLE test_cases (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id      INTEGER NOT NULL REFERENCES projects(id),
    module          TEXT,           -- 功能模块
    title           TEXT NOT NULL,
    precondition    TEXT,           -- 前置条件
    steps           JSON NOT NULL,  -- 测试步骤
    expected        TEXT,           -- 预期结果
    priority        TEXT DEFAULT 'medium',
    status          TEXT DEFAULT 'draft',
    created_by      INTEGER REFERENCES users(id),
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2.3 数据模型
```sql
CREATE TABLE data_sources (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id      INTEGER NOT NULL REFERENCES projects(id),
    name            TEXT NOT NULL,
    type            TEXT NOT NULL,   -- database/csv/api/mock
    config          JSON NOT NULL,   -- 连接配置
    status          TEXT DEFAULT 'active',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE masking_rules (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    name            TEXT NOT NULL,
    field_pattern   TEXT NOT NULL,   -- 字段匹配模式
    strategy        TEXT NOT NULL,   -- 脱敏策略
    config          JSON,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE mock_services (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id      INTEGER NOT NULL REFERENCES projects(id),
    name            TEXT NOT NULL,
    config          JSON NOT NULL,   -- Mock配置
    status          TEXT DEFAULT 'active',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
