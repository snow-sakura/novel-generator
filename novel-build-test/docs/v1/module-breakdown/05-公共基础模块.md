## 1. 认证与安全 (auth)

### 1.1 功能清单

| 功能 | 类型 | 说明 |
|------|------|------|
| 用户注册 | CREATE | 用户名/邮箱/密码注册 |
| 用户登录 | ACTION | JWT令牌登录 |
| 获取用户信息 | READ | 获取当前用户信息 |
| 令牌刷新 | ACTION | Access Token刷新 |
| 退出登录 | ACTION | 令牌失效 |

### 1.2 API 接口

```
POST   /api/v1/auth/register               # 用户注册
POST   /api/v1/auth/login                  # 用户登录
GET    /api/v1/auth/me                     # 获取当前用户
POST   /api/v1/auth/refresh                # 令牌刷新
POST   /api/v1/auth/logout                 # 退出登录
```

### 1.3 数据模型

```sql
CREATE TABLE users (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    username        TEXT NOT NULL UNIQUE,
    email           TEXT NOT NULL UNIQUE,
    password_hash   TEXT NOT NULL,
    display_name    TEXT,
    avatar_url      TEXT,
    role            TEXT DEFAULT 'user',  -- user/admin
    status          TEXT DEFAULT 'active',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    deleted_at      DATETIME
);
```

### 1.4 页面组件

```
pages/auth/
├── LoginPage.tsx               # 登录页
└── RegisterPage.tsx            # 注册页
```

## 2. 系统设置 (settings)

### 2.1 功能清单

| 功能 | 类型 | 说明 |
|------|------|------|
| 设置列表 | READ | 查询所有配置项 |
| 设置详情 | READ | 查看配置项详情 |
| 创建设置 | CREATE | 新增配置项 |
| 更新设置 | UPDATE | 修改配置值 |
| 删除设置 | DELETE | 删除配置项 |

### 2.2 API 接口

```
GET    /api/v1/settings                     # 设置列表
GET    /api/v1/settings/:key                # 设置详情
POST   /api/v1/settings                     # 创建设置
PUT    /api/v1/settings/:key                # 更新设置
DELETE /api/v1/settings/:key                # 删除设置
```

### 2.3 数据模型

```sql
CREATE TABLE settings (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    key             TEXT NOT NULL UNIQUE,
    value           TEXT NOT NULL,
    description     TEXT,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2.4 页面组件

```
pages/settings/
├── SettingsPage.tsx            # 系统设置页
```

## 3. 审计日志 (audit)

### 3.1 功能清单

| 功能 | 类型 | 说明 |
|------|------|------|
| 日志列表 | READ | 分页查询操作日志 |
| 日志详情 | READ | 查看日志详情 |
| 实体操作轨迹 | READ | 查看指定实体的操作历史 |

### 3.2 API 接口

```
GET    /api/v1/audit-logs                   # 日志列表（分页）
GET    /api/v1/audit-logs/:id               # 日志详情
GET    /api/v1/audit-logs/entity/:type/:id  # 实体操作轨迹
```

### 3.3 数据模型

```sql
CREATE TABLE audit_logs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id         INTEGER REFERENCES users(id),
    action          TEXT NOT NULL,   -- create/update/delete
    entity_type     TEXT NOT NULL,   -- 实体类型
    entity_id       INTEGER,         -- 实体ID
    changes         JSON,            -- 变更内容
    ip_address      TEXT,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 3.4 页面组件

```
pages/audit/
└── AuditListPage.tsx           # 日志列表页
```
