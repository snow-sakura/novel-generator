## 版本变更

### v1.1.0 (2026-07-15)

**新增功能:**
- Docker容器化支持 — 新增Dockerfile和docker-compose.yml配置
- MCP工具集成 — 新增MCP工具管理和调用接口
- 角色权限管理 — 完善角色管理、用户管理、权限控制
- 测试执行管理 — 新增测试执行记录和报告分析
- 模型分级策略 — 实现L1-L5模型分级，按任务复杂度自动选择
- 前端UI优化 — 新增分页组件、文本区域、占位符页面等

**模块完善:**
- Hermes智能体配置 — 完善会话管理、消息读写、事件轮询
- Skills技能中心 — 完善技能CRUD、MCP工具管理、权限配置
- 测试报告分析 — 新增报告生成、对比分析功能
- 认证安全 — 完善JWT认证、密码修改、用户管理

**开发完成:**
- 全部 108 个任务已完成（Phase 1-4）
- 21 大模块、81 二级功能全部实现
- 前后端代码已通过测试
