# AISQA v1 版本文档

> 版本: v1.2.0
> 更新日期: 2026-07-18
> 状态: v1.2.0 已完成，v1.3.0 规划中

## 版本变更

### v1.2.0 (2026-07-15)

**里程碑: 42 模块全量上线**

**AI 基础设施完善:**
- LLM Provider 工厂 — OpenAICompatibleProvider + 定价注册表
- Agent 基类 — 统一 LLM 调用 + 重试 + 反射机制
- 向量数据库 — Qdrant 集成，支持语义检索
- 事件总线 — Redis Pub/Sub，实时状态同步
- RAG 管道 — 文档加载、分块、向量化、检索

**后端 API 补全:**
- 37 个路由文件、22 个 SQLAlchemy 模型、18 个 Pydantic Schema
- 287 个 API 端点，覆盖全部 42 模块
- 完整的 Agent 端点（发起/状态/结果/历史）

**前端框架:**
- React 19 + TypeScript + Vite + Tailwind CSS v4
- shadcn/ui + Radix UI Primitives + framer-motion
- 22 个前端模块，全部页面已注册
- Polaroid 暖白拍立得设计语言

**DevOps:**
- Docker 全栈容器化（MySQL + Redis + Qdrant + Backend + Frontend）
- 健康检查、数据持久化、环境变量管理
- pre-commit hooks（Ruff lint + format）

### v1.1.0 (2026-07-15)

**新增功能:**
- Docker容器化支持 — 新增Dockerfile和docker-compose.yml配置
- MCP工具集成 — 新增MCP工具管理和调用接口
- 角色权限管理 — 完善角色管理、用户管理、权限控制
- 测试执行管理 — 新增测试执行记录和报告分析
- 模型分级策略 — 实现L1-L5模型分级，按任务复杂度自动选择
- 前端UI优化 — 新增分页组件、文本区域、占位符页面等

**开发完成:**
- 全部 108 个任务已完成（Phase 1-4）
- 21 大模块、81 二级功能全部实现

### v1.0.0 (2026-07-14)

**新增模块:**
- Hermes智能体配置 — 消息桥接、会话管理、通道与权限配置
- Skills技能中心 — 技能注册、MCP工具管理、权限控制、技能市场

**模块总数:** 19 → 21
**二级功能总数:** 69 → 81
