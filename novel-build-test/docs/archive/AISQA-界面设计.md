# AISQA 界面设计

## 布局
- 可折叠侧边栏（64px ⇔ 240px）
- 顶部导航栏（页面标题 + 用户菜单）
- 内容区域（Outlet 渲染）

## 页面清单
1. 登录/注册 — 居中卡片式
2. 仪表盘 — 统计卡片 + 最近活动 + 快速入口
3. 项目管理 — 搜索 + 表格 + CRUD
4. 需求管理 — 需求列表 + 状态流转
5. 测试用例 — 用例表格 + 详情
6. 执行记录 — 执行列表 + 状态
7. 报告 — 报告列表 + 下载
8. 审计日志 — 操作轨迹表格
9. AI 可视化 — 智能体监控 + 辩论看板 + 成本仪表盘
10. 设置 — 个人资料 + 密码修改
