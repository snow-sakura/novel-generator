# AISQA 多智能体生命周期设计 v2.0

## 智能体定义（全中文命名）

### 1. 调度总控
- 职责：任务分发、流程编排、仲裁决策
- 触发条件：新测试任务创建、辩论僵局、定时调度
- 输出：工作流定义、仲裁结果

### 2. 需求分析
- 职责：解析需求文档、提取测试要点
- 输入：PRD/需求文档
- 输出：需求分析报告、测试范围

### 3. 测试架构
- 职责：设计测试架构、选择测试策略
- 输入：需求分析报告
- 输出：测试架构方案

### 4. 测试设计
- 职责：设计测试场景、编写测试方案
- 输入：测试架构方案
- 输出：测试设计文档

### 5. 用例编写
- 职责：生成测试用例、维护用例库
- 输入：测试设计文档
- 输出：测试用例集

### 6. 执行分析
- 职责：执行测试、收集结果、分析失败
- 输入：测试用例集
- 输出：执行报告、缺陷分析

### 7. 质量审计
- 职责：质量评估、合规检查、最终报告
- 输入：执行报告
- 输出：质量审计报告

## 辩论机制
- 分歧发现 → 3轮辩论 → 共识检查 → 调度总控仲裁
- 交叉验证：同一决策由 DeepSeek-V3 + GLM-4 或 Qwen-Max 验证
