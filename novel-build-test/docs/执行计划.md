## 2. Phase 3：AI Agent 系统（待实现）

### 概述

AI Agent 系统是 AISQA 平台的核心智能层。**后端骨架已完成**（7 个 Agent + LangGraph 工作流 + AutoGen 辩论引擎 + 调度总控），但：
- 所有 Agent 尚未连接真实 LLM（API Key 未配置，运行时返回 "LLM Provider 不可用"）
- 前端 Agent 管理页面尚未实现
- 缺少完整的 Agent 调用链路集成测试

### 2.1 后端：LLM Provider 配置（前置条件）

| 编号 | 子模块 | 文件 | 详细说明 | 优先级 |
|------|--------|------|---------|--------|

| 2.1.2 | Provider 工厂验证 | `app/services/llm/provider.py` | 验证 4 个 Provider 的 chat() 接口能否正常返回，确保流式/非流式均通 | P0 |
| 2.1.3 | 模型分级配置表 | `app/services/llm/model_tier.py` | **新增**: 定义 L1~L4 模型分级常量表（模型名、单价、支持场景、最大 token），供 CostOptimizer 读取 | P0 |
| 2.1.4 | 连接 DB settings 表 | `app/services/llm/provider.py` | 支持从 `settings` 表动态读取 LLM 配置（provider/model/key/base_url），页面修改无需重启 | P1 |

### 2.2 后端：7 个 Agent 的 LLM 调用接通

每个 Agent 当前 execute() 方法返回占位文本。需改为：
1. 调用 `self._call_llm(prompt)` 或 `self._execute_with_retry(prompt)`
2. 构建场景相关的 SYSTEM_PROMPT
3. 解析 LLM 返回的 JSON/文本
4. 返回 AgentResult

| 编号 | 子模块 | Agent | 详细说明 | 优先级 |

| 2.2.1 | Agent 提示词工程 | RequirementsAnalyst | 编写 SYSTEM_PROMPT：接收 PRD/需求列表，输出 JSON 格式的测试要点（功能点/边界条件/异常场景），含 JSON Schema 约束 | P0 |
| 2.2.2 | Agent 提示词工程 | TestArchitect | 编写 SYSTEM_PROMPT：接收需求分析结果，输出测试架构方案（技术栈建议、分层策略、环境需求） | P0 |
| 2.2.3 | Agent 提示词工程 | TestDesigner | 编写 SYSTEM_PROMPT：接收架构方案，输出测试场景列表（功能/性能/安全/兼容性场景） | P0 |
| 2.2.4 | Agent 提示词工程 | TestCaseWriter | 编写 SYSTEM_PROMPT：接收测试场景，输出详细测试用例（前置/步骤/预期/数据） | P0 |
