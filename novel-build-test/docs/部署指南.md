# 部署指南

## 一、环境要求

| 组件 | 版本要求 | 用途 |
|------|---------|------|
| Python | ≥3.12 | 后端运行环境 |
| Node.js | ≥22 | 前端构建 |
| pnpm | ≥9 | 前端包管理 |
| MySQL | ≥9.0 | 关系数据库 |
| Redis | ≥7.x | 事件总线 + 缓存 |
| Qdrant | ≥1.13 | 向量数据库 |

---

## 二、基础设施安装

### macOS (Homebrew)

```bash
# MySQL
brew install mysql@9.0
brew services start mysql

# Redis
brew install redis
brew services start redis

# Qdrant（本地二进制）
curl -L https://github.com/qdrant/qdrant/releases/latest/download/qdrant-x86_64-apple-darwin.tar.gz | tar xz
# 或使用 arm64 版本（Apple Silicon）
curl -L https://github.com/qdrant/qdrant/releases/latest/download/qdrant-aarch64-apple-darwin.tar.gz | tar xz
```

### 初始化 MySQL 数据库

```bash
mysql -u root -p

# 创建数据库
CREATE DATABASE IF NOT EXISTS aisqa CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建用户（如需要）
CREATE USER 'aisqa'@'localhost' IDENTIFIED BY 'your-password';
GRANT ALL PRIVILEGES ON aisqa.* TO 'aisqa'@'localhost';
FLUSH PRIVILEGES;
```

### 启动 Qdrant

```bash
# 带持久化路径启动
./qdrant --storage-path ./qdrant_storage
# Qdrant 默认监听 localhost:6333 (HTTP) 和 localhost:6334 (gRPC)
```

## 三、后端部署

### 3.1 环境配置

```bash
cd novel-build-test/backend

# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 3.2 环境变量

编辑 `backend/.env`：

```env
APP_NAME="AISQA"
DEBUG=false

# MySQL 数据库
DATABASE_URL="mysql+aiomysql://root:Wxh123456!@127.0.0.1:3306/aisqa"

# JWT 配置
JWT_SECRET_KEY="your-secret-key-change-in-production"
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30
JWT_REFRESH_TOKEN_EXPIRE_DAYS=7

# CORS
CORS_ORIGINS='["http://localhost:5173"]'

# 国产大模型 API Key（按需配置）
DEEPSEEK_API_KEY=""
DEEPSEEK_BASE_URL="https://api.deepseek.com/v1"
QWEN_API_KEY=""
QWEN_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
GLM_API_KEY=""
GLM_BASE_URL="https://open.bigmodel.cn/api/paas/v4"
MOONSHOT_API_KEY=""
MOONSHOT_BASE_URL="https://api.moonshot.cn/v1"

# Qdrant 向量数据库
QDRANT_HOST="127.0.0.1"
QDRANT_PORT=6333

# Redis 事件总线
REDIS_URL="redis://localhost:6379/0"
```

### 3.3 数据库迁移

```bash
# 执行已有迁移
alembic upgrade head

# 创建新迁移（模型变更后）
alembic revision --autogenerate -m "描述变更内容"
alembic upgrade head
```

### 3.4 启动

```bash
# 开发模式（热重载）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 生产模式
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

### 3.5 验证

```bash
curl http://localhost:8000/api/v1/health
# 预期: {"status":"ok","app":"AISQA","version":"1.0.0","子系统状态":{...}}
```

## 四、前端部署

### 4.1 安装依赖

```bash
cd novel-build-test/frontend

# 安装 pnpm（如未安装）
npm install -g pnpm

# 安装依赖
pnpm install
```

### 4.2 开发模式

```bash
pnpm dev
# 访问 http://localhost:5173
```

### 4.3 生产构建

```bash
# 构建
pnpm build

# 构建产物在 dist/ 目录
# 可使用 nginx 等静态服务器部署
```

### 4.4 Nginx 配置示例

```nginx
server {
    listen 80;
    server_name aisqa.local;

    # 前端静态文件
    root /path/to/novel-build-test/frontend/dist;
    index index.html;

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 五、验证全链路

启动顺序：MySQL → Redis → Qdrant → 后端 → 前端

```bash
# 1. 验证 MySQL
mysql -u root -p -e "USE aisqa; SELECT 1;" && echo "✅ MySQL OK"

# 2. 验证 Redis
redis-cli ping && echo "✅ Redis OK"

# 3. 验证 Qdrant
curl -s http://localhost:6333/health && echo "✅ Qdrant OK"

# 4. 验证后端
curl -s http://localhost:8000/api/v1/health && echo "✅ Backend OK"

# 5. 验证前端
curl -s -o /dev/null -w "%{http_code}" http://localhost:5173 && echo "✅ Frontend OK"
```

## 六、常见问题

### Q1: 数据库连接失败？
```
确保 MySQL 已启动：brew services start mysql
检查连接字符串中的密码是否正确
```

### Q2: Qdrant 无法连接？
```
确保 qdrant 二进制正在运行
检查端口 6333 是否被占用：lsof -i :6333
从日志查看：./qdrant --storage-path ./qdrant_storage
```

### Q3: LLM API Key 未配置？
```
智能体执行时会返回 "LLM Provider 不可用"
这是预期行为，在 .env 中配置对应 API Key 即可
```

### Q4: Redis 连接失败？
```
检查 Redis 是否运行：brew services list | grep redis
查看 Redis 日志：brew services restart redis
```

### Q5: 前端 TypeScript 报错？
```
确保 pnpm install 已执行
检查 node 版本：node -v (需 ≥22)
尝试删除 node_modules 重新安装
```
