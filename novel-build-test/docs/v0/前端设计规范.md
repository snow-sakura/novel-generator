# 前端设计规范 — 暖白拍立得风格

## 一、设计理念

AISQA 前端采用 **"暖白拍立得"** 设计语言，灵感来源于：
- 拍立得相纸的纯白质感与温暖色调
- 老照片的自然随机旋转与双层阴影
- 极简舒适的阅读体验

**关键词**: 温暖、极简、质感、随机、自然

## 三、组件规范

### 3.1 PolaroidCard（拍立得卡片）

```
┌──────────────────────────────────┐  ← 圆角 12px, 纯白背景
│                                  │
│         ┌────────────────┐       │
│         │   图标/颜色区    │       │  ← 64×64 图标或渐变色块
│         │                │       │
│         └────────────────┘       │
│         标题文字                  │  ← text-lg font-semibold
│         辅助统计数字              │  ← text-2xl font-bold amber
│         次要描述                  │  ← text-sm text-muted-foreground
│                                  │
│    ┌────────────────────────┐    │
│    │   底部签名区(signature)  │    │  ← 拍立得底部留白区域
│    │   标签/副标题/状态       │    │
│    └────────────────────────┘    │
│                                  │
└──────────────────────────────────┘
         ↑ 随机旋转 -2deg ~ +2deg

规格:
- 宽度: w-72 (288px)
- 背景: white / bg-card
- 圆角: rounded-xl (12px)
- 阴影: shadow-polaroid (自定义多层暖棕阴影)
- 旋转: 随机 -2deg ~ +2deg (每个卡片创建时固定)
- 悬浮: hover:-translate-y-2 hover:rotate-0 hover:shadow-2xl
- 动画: transition-all duration-300 ease-out
```

### 3.2 PolaroidGrid（卡片矩阵）

- 使用 CSS Grid 布局
- 默认 5 列（公共模块），3~5 列自适应
- 卡片交错排列（自然错落）
- 入场动画：逐张淡入上滑（stagger 0.08s）

### 3.3 双层导航

```
第一层: 首页卡片矩阵 (点击卡片)
              │
              ▼
第二层: 详情页内部 ┌── 左侧导航 ──┐ ┌── 右侧内容 ──┐
                 │ • 概览       │ │              │
                 │ • 列表/表单  │ │  内容区域     │
                 │ • 配置       │ │              │
                 └──────────────┘ └──────────────┘
```

- 左侧导航：w-56，暖白背景，激活项琥珀高亮
- 右侧内容：flex-1，可滚动
- 导航收起态：w-16，仅图标

### 3.4 AI 助手悬浮窗 (Intercom 风格)

```
              ┌──────────────────┐
              │     🤖 AI 助手    │  ← 悬浮按钮，固定在右下角
              │                  │     size: 56px, 圆形
              │  ┌──────────┐    │     bg: amber-primary
              │  │ 消息气泡   │    │     shadow: 暖色阴影
              │  │ 建议按钮   │    │
              │  │ 输入框    │    │
              │  └──────────┘    │
              │                  │
              └──────────────────┘
```

- 初始状态：圆形悬浮按钮（右下角，距底部 24px，距右侧 24px）
- 点击展开：300px × 400px 弹窗
- 弹窗内容：消息列表 + 快捷建议按钮 + 输入框
- 动画：缩放展开 + 弹性过渡

### 3.5 STLC 生命周期环

- SVG 圆形进度环
- 6 个节点：需求分析 → 测试计划 → 用例设计 → 环境准备 → 测试执行 → 报告生成
- 已完成节点：金色填充
- 当前节点：脉冲动画
- 待办节点：灰色轮廓
- 节点间连线：描边动画

## 四、交互动画

| 场景 | 动画 | 实现 |
|------|------|------|
| 首页入场 | 卡片逐张淡入 + 上滑 | framer-motion staggerChildren |
| 卡片悬浮 | translateY(-8px) + rotate(0) + scale(1.02) | CSS transition |
| 卡片点击 | scale(0.95) → 翻转 → 进入详情 | framer-motion |
| 页面切换 | 淡入淡出 (fadeIn/out) | framer-motion AnimatePresence |
| 侧边栏展开 | 宽度 0→240px 弹性展开 | CSS transition + spring |
| 进度环 | SVG strokeDashoffset 动画 | CSS animation |
| AI 消息 | 气泡从底部弹出 + 打字机效果 | framer-motion |
