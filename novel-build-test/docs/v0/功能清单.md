## 10. 去AI味配置 ⏳

| # | 二级功能 | 说明 |
|---|---------|------|
| 10.1 | 语言风格控制 | 调整 AI 输出语感：专业正式 / 口语化 / 中性默认 |
| 10.2 | 句式多样性 | 随机变换句式结构（长短句交替、主被动切换、倒装/省略） |
| 10.3 | 领域术语注入 | 自动注入项目/行业专属术语，让输出更像领域专家 |
| 10.4 | 人性化细节 | 添加适度不完美：口语化连接词、非标准缩写，增强真人感 |
| 10.5 | 输出模板约束 | 强制输出格式模板，禁止 AI 常见的编号列表+总结段落模式 |
| 10.6 | 去AI味强度 | 滑块控制：关闭 / 轻度 / 中度 / 重度 |
| 10.7 | 词频黑名单 | 配置禁用词列表（"值得注意的是"、"总而言之"等），自动替换 |
