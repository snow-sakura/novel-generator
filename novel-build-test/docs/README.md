## 当前版本 (v1.2.0)

- 42 大模块，7 个分组，287 个 API 端点
- AI 基础设施：LLM Provider 工厂、模型分级、Agent 基类、向量数据库、事件总线、RAG 管道、MCP 协议
- 9 个 Agent 类（基类 + 7 专业 + 辩论引擎）
- 前端页面框架完整，22 个前端模块
- Docker 全栈容器化（MySQL + Redis + Qdrant + Backend + Frontend）

## 下一版本 (v1.3.0) 规划

- **Agent 增强**: DAG 编排引擎、MCP 工具注册、多 Agent 协作、知识库 RAG 增强
- **测试能力**: AI 驱动测试生成、可视化报告、CI 深度集成、测试数据工厂
- **DevOps**: Docker 多阶段构建、nginx 反向代理、多环境配置
- **平台体验**: 暗色模式、全局搜索、仪表盘、i18n、快捷键
- **代码质量**: Ruff + ESLint/Prettier、pre-commit、类型覆盖、OpenAPI SDK
