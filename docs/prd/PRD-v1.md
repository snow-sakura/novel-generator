# 番茄小说生成智能体 — 需求文档 v1

## 项目概述
输入一句话，自动生成一篇完整小说（短篇/中篇/长篇）。

---

## 故事创作三层架构

| 层级 | 维度 | 说明 |
|------|------|------|
| **骨架** | 人物、情节、环境 | 故事六要素，小说的基础 |
| **血肉** | 视角、节奏、语言风格 | 叙事层面的呈现艺术 |
| **灵魂** | 主题、情感共鸣 | 思想价值层面 |

### 归纳三点
1. **基础要素** — 人物、情节、环境、视角、语言风格、主题
2. **骨架支撑** — 节奏感、张力、细节真实感
3. **优秀附加值** — 情感共鸣、思想启迪、美学享受、意义探寻

---

## 版本规划

### V1 — 骨架版（基础生成）
> 目标：能生成"一个完整的故事"，保证结构正确

**功能列表：**
1. **一句话输入** — 用户输入任意自然语言，作为小说种子
2. **题材/类型/风格选择** — 提供下拉选项（玄幻/都市/悬疑/言情/科幻/历史，短篇/中篇/长篇）
3. **字数限制设定** — 用户可指定目标字数（2000/5000/10000+）
4. **基础生成引擎** — 自动补全故事六要素（人物、时间、地点、起因、经过、结果）
5. **分段输出** — 按章节/段落结构化输出，可读性优先

**V1 不做：** 多轮修改、复杂设定、情感深度

---

### V2 — 血肉版（叙事升级）
> 目标：让故事"好看"，具备叙事技巧

**功能列表：**
1. **视角控制** — 支持第一人称/第三人称/上帝视角切换
2. **节奏调节** — 快节奏（剧情紧凑）/慢节奏（细腻描写）模式
3. **语言风格预设** — 简洁直白/文艺抒情/幽默诙谐/冷峻写实
4. **叙事张力增强** — 自动制造冲突、悬念、反转
5. **细节填充** — 环境描写、心理活动、对话润色
6. **多轮对话润色** — 用户可对某一段落要求重写/扩写/精简

**V2 不做：** 主题深度挖掘、跨章节一致性校验

---

### V3 — 灵魂版（价值升华）
> 目标：让故事"值得回味"，具备思想与情感穿透力

**功能列表：**
1. **主题设定** — 用户指定核心主题（救赎/成长/选择/正义/爱情等），AI 围绕主题展开
2. **情感曲线规划** — AI 自动设计起承转合的情感波动图（开心 → 低谷 → 高潮 → 释然）
3. **金句生成** — 在关键节点自动插入富有哲理的句子
4. **美学风格渲染** — 整体语言美感提升，画面感更强
5. **意义提炼** — 生成完成后附带"故事核心解读"，揭示主题与寓意
6. **跨章节一致性** — 人物性格、世界观设定前后统一，不崩人设
7. **版本对比与迭代** — 同一输入可生成多个不同版本供用户挑选

---

## 核心流程（贯穿三个版本）

```
用户输入一句话
       ↓
选择题材 / 类型 / 风格 / 字数 / 主题（V3）
       ↓
AI 分析 → 补全六要素 → 构建大纲 → 逐章生成
       ↓
输出完整小说（可逐段查看 / 导出）
```

## 非功能需求
- 响应速度：短篇生成 ≤ 10 秒，中篇 ≤ 30 秒，长篇 ≤ 60 秒
- 输出格式：支持 Markdown 和纯文本导出
- 接口设计：所有版本功能均通过 API 调用，前端可解耦
