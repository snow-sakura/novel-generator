# 番茄小说生成智能体 V2 — 需求文档（血肉版）

## 版本目标

V1 解决了"能不能生成一个完整故事"的问题，V2 在此基础上解决"故事好不好看"的问题——引入叙事技巧，提升阅读体验。

---

## 与 V1 的增量关系

```
V1（骨架）  →  保证"能看"
V2（血肉）  →  追求"好看"
V3（灵魂）  →  追求"值得回味"
```

V2 不重写 V1，而是在 V1 的基础上叠加叙事层能力。

---

## 功能列表

### F1 — 视角控制

| 项目 | 说明 |
|------|------|
| 概述 | 用户可选择叙事视角，AI 按选定视角生成全文 |
| 可选视角 | 第一人称（"我"）/ 第三人称有限（跟随主角）/ 上帝视角（全知） |
| 交互 | 生成表单增加「叙事视角」下拉选择 |
| 约束 | 选定后全篇保持一致，不随意切换 |

### F2 — 节奏调节

| 项目 | 说明 |
|------|------|
| 概述 | 用户指定节奏模式，AI 控制叙事密度和推进速度 |
| 可选模式 | **紧凑型**（对话多、描述少、推进快） / **舒缓型**（环境描写细腻、心理活动丰富） / **标准型**（默认均衡） |
| 实现思路 | 通过 Prompt 控制段落长度、描写占比、对话密度 |
| 交互 | 生成表单增加「节奏模式」单选 |

### F3 — 语言风格预设

| 项目 | 说明 |
|------|------|
| 概述 | V1 已支持 4 种风格，V2 细化为风格强度控制 |
| 风格 + 强度 | 用户选择风格后，额外选择「轻度 / 中度 / 重度」 |
| 示例 | 文艺抒情（轻度）= 偶尔优美修辞；文艺抒情（重度）= 通篇诗意表达 |
| 交互 | 风格选择后弹出强度滑块 |

### F4 — 叙事张力增强

| 项目 | 说明 |
|------|------|
| 概述 | AI 自动在故事中植入冲突、悬念、反转等叙事元素 |
| 具体能力 | • **冲突设计**：角色之间的矛盾、目标冲突 |
| | • **悬念设置**：章节末尾留钩子（Cliffhanger） |
| | • **反转安排**：故事中期或结尾出现意外转折 |
| 交互 | 用户可在生成前勾选「启用悬念」「启用反转」 |
| 约束 | 反转不超过 2 次，避免为转而转 |

### F5 — 细节填充

| 项目 | 说明 |
|------|------|
| 概述 | 在骨架基础上自动填充三类细节 |
| 细节类型 | • **环境描写**：场景视觉、听觉、嗅觉细节 |
| | • **心理活动**：主角内心独白、情绪变化 |
| | • **对话润色**：根据角色性格设计说话方式 |
| 交互 | 无额外交互，V2 默认启用 |

### F6 — 多轮对话润色

| 项目 | 说明 |
|------|------|
| 概述 | 生成完成后，用户可针对特定段落要求 AI 修改 |
| 支持操作 | • **重写**：不满意当前段落，重新生成 |
| | • **扩写**：段落太短，增加更多细节 |
| | • **精简**：段落太啰嗦，压缩到核心内容 |
| 交互 | 每段末尾显示「重写」「扩写」「精简」按钮 |
| 边界 | V2 只支持单段操作，不支持跨段联动修改 |

## 三层架构对照（V2 覆盖范围）

| 层级 | 维度 | V2 覆盖 |
|------|------|----------|
| **骨架** | 人物、情节、环境 | ✅ 继承 V1 |
| **血肉** | 视角、节奏、语言风格 | ✅ 新增 F1/F2/F3 |
| | 细节真实感 | ✅ 新增 F5 |
| | 张力、悬念、反转 | ✅ 新增 F4 |
| | 可修改性 | ✅ 新增 F6 |
| **灵魂** | 主题、情感共鸣 | ❌ V3 实现 |

---

## 非功能需求（V2 新增）

- 润色响应时间 ≤ 5 秒
- 风格强度切换后，全篇语言风格一致性校验
- 节奏模式下字数偏差控制在 ±15% 以内
- 多轮润色保留历史版本（最多 3 版）

---

## 依赖关系

- V2 依赖 V1 的生成管线、数据库、前端页面结构
- 在 V1 基础上新增组件：StyleIntensitySlider、TensionOptions、ParagraphActions
- 后端新增服务：RefineService（润色）
