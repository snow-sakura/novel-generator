# 番茄小说生成智能体 V3 — 需求文档（灵魂版）

## 版本目标

在 V1（骨架）+ V2（血肉）的基础上，V3 解决"故事有什么价值"的问题——赋予故事思想深度和情感穿透力，让读者产生共鸣。

---

## 与 V1/V2 的递进关系

```
V1（骨架）  →  能看（结构完整）
V2（血肉）  →  好看（叙事技巧）
V3（灵魂）  →  耐看（思想情感）
```

V3 依赖 V1 + V2 的所有能力，在此之上叠加价值层。

---

## 功能列表

### F1 — 主题设定与贯穿

| 项目 | 说明 |
|------|------|
| 概述 | 用户指定/AI 推荐核心主题，全篇围绕主题展开 |
| 可选主题 | 救赎 / 成长 / 选择 / 正义 / 爱情 / 自由 / 牺牲 / 希望 / 孤独 / AI 推荐 |
| 交互 | 生成表单增加「主题」下拉 + "让 AI 推荐"按钮 |
| 约束 | 主题必须贯穿全篇，结尾回扣主题点题 |

### F2 — 情感曲线规划

| 项目 | 说明 |
|------|------|
| 概述 | AI 在生成前规划情感波动曲线，确保起承转合有情绪节奏 |
| 曲线结构 | **起**（引入，平静/好奇）→ **承**（发展，期待/温暖） |
| | → **转**（冲突，紧张/悲伤）→ **合**（结局，释然/感动） |
| 可视化 | 生成完成后展示「情感曲线图」（情绪标签 + 对应章节） |
| 交互 | 用户可手动调整曲线节点后再生成 |

### F3 — 金句生成

| 项目 | 说明 |
|------|------|
| 概述 | AI 在关键节点自动插入富有哲理的句子，提升文学质感 |
| 插入时机 | • 章节结尾处 |
| | • 情感高潮处 |
| | • 主角领悟/转折时刻 |
| 样式 | 用引用块或斜体标识，与正文区分 |
| 交互 | 用户可在润色模式下手动标注「在此插入金句」 |

### F4 — 美学风格渲染

| 项目 | 说明 |
|------|------|
| 概述 | AI 整体提升语言美感，使文字更具画面感和文学性 |
| 渲染维度 | • **比喻与意象**：适当使用隐喻、拟人等修辞 |
| | • **节奏韵律**：长短句交替，读起来有节奏感 |
| | • **画面感**：场景描写如电影镜头般具象 |
| 交互 | 新增「美学强度」滑块（关闭 / 轻度 / 中度 / 重度） |
| 约束 | 重度模式下可能牺牲部分阅读速度，默认中度 |

### F5 — 意义提炼（文末解读）

| 项目 | 说明 |
|------|------|
| 概述 | 生成完成后，AI 自动生成一段"故事解读"，揭示主题和寓意 |
| 解读内容 | • **主题提炼**：这篇故事在讲什么 |
| | • **人物弧光**：主角经历了怎样的成长/变化 |
| | • **现实映射**：故事和现实生活的关联 |
| 展示位置 | 小说正文结束后，以「—— 编者按」样式独立展示 |
| 交互 | 用户可选择「不显示解读」 |

### F6 — 跨章节一致性

| 项目 | 说明 |
|------|------|
| 概述 | 确保全篇人物性格、世界观设定、时间线前后统一 |
| 一致性维度 | • **人设一致性**：角色行为不违背初始设定 |
| | • **世界观一致性**：力量体系/科技水平不矛盾 |
| | • **时间逻辑**：事件顺序合理，无时间悖论 |
| | • **名称一致性**：角色名、地名、物品名前后一致 |
| 实现思路 | 生成过程中维护「设定档案」（Character Bible），每章生成时引用 |
| 交互 | 用户可查看/编辑「设定档案」 |

### F7 — 版本对比与迭代

| 项目 | 说明 |
|------|------|
| 概述 | 同一输入可快速生成多个不同版本供用户挑选 |
| 对比维度 | • 不同风格（所有风格各生成一版） |
| | • 不同视角（三种视角各生成一版） |
| | • 不同结局（好结局 / 坏结局 / 开放式） |
| 展示 | 并排对比 / 切换对比 两种模式 |
| 交互 | 选中满意版本后，可继续在 V2 润色基础上精修 |

## 非功能需求（V3 新增）

- 设定档案大小 ≤ 10KB
- 情感曲线图支持导出为图片
- 多版本对比时，切换响应 ≤ 2 秒
- 全文一致性校验通过率 ≥ 95%（AI 自检）
- 金句密度：每 2000 字 1-2 句为佳

- V3 依赖 V1 生成管线 + V2 润色能力
